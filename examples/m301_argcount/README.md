# M301 · 函数调用「实参个数」三轨全量对拍（缺陷 518）

第 111 轮。修前 **21 例 ⇒ 13 例分叉**（三轨四种行为），修后 **0 例分叉**。

## 一 这一面为什么此前没人量过

M226 量过**方法面**、M227 量过「同名两门」（函数面 ⇄ 方法面）、M230 量过索引/切片族、
M231 量过 `(运算符 × 类型)` 矩阵、M232 量过真值性表 —— 而**函数调用的实参个数**
这一面从来没有被清单级度量过。它是「每行代码都在用」的最基础面，
正是三轨各自为政的地方。

## 二 缺陷 518 的四个形状（修前实测）

| 形状 | 解释轨 | VM 轨 | C 轨 |
|---|---|---|---|
| **多给**（`f2(1,2,3)`） | `R1005 参数过多` | **静默忽略** = 3 | **静默忽略** = 3 |
| **多给**（`z0(1)` 零参） | `R1005 参数过多` | 静默 = 7 | 静默 = 7 |
| **少给·无默认值**（`f2(1)`） | `R1005 缺少参数 'b'` | `R1005 需 2 给 1` | **静默绑 null** ⇒ 下游 `R1002 无法相加: int + null` |
| **少给·有默认值**（`g2(1)`） | 11 ✓ | 11 ✓ | 11 ✓ |
| **闭包少给·有默认值**（`fn (x, y = 5)` 调 `(1)`） | 6 ✓ | **`R1005 需 2 给 1`** | **丢默认值** ⇒ `R1002` |
| **方法多给**（`p.scaled(3,1,9)`） | `R1005` | 静默 = 4 | 静默 = 4 |
| **方法少给**（`p.scaled()`） | `R1005 缺少参数 'k'` | **`R1002 无法相乘`** | **`R1002 无法相乘`** |

两个方向都危险：**多给**是静默错值；**少给**在 C/VM 轨要等函数体用到参数才在下游炸
（错误指不到真因 —— 同 M185 族）。

## 三 修法（四处 · 两轨）

| 位置 | 内容 |
|---|---|
| `selfhost/codegen.px` `cg_gen_func_named` | 函数体开头发射 arity 前置检查（**顶层函数与 impl 方法同构**）⇒ 直调 / 间接 / 回调 / `px_method` 一并覆盖 |
| `selfhost/cg_expr.px` `cg_gen_closure` | 同上 + **默认值补齐**（修前 `px_null()` 硬编码，默认表达式从不求值） |
| `runtime/vm.c` **新增** `vm_check_arity()` | 实参个数的唯一判据（下界 + **上界**）；`total = arity + ndefault` |
| `runtime/vm.c` 四个调用点 | `CALL`（普通 / 闭包）· **`px_vm_entry`** · **`px_vm_closure_entry`** |
| `selfhost/bc_emit.px` `bc_emit_push_lambda` | 闭包识别默认参数（arity/ndefault）+ 入口 `bc_emit_default_fill` |

**为什么 `px_vm_entry` 是必须的**：`x.m()` 在 VM 轨走 `CALLM → px_method → px_call
→ px_vm_entry`，**不经过 `CALL` 指令** ⇒ 只修 `CALL` 的话方法面仍分叉。

**口径**（与解释轨对齐 = 基准）：多给一律响亮 `R1005`；少给按 M90-S1
「默认参数在尾部」—— required = 首个带默认值的形参下标，缺的补默认值，无默认值则响亮。

## 四 判据分层

1. **静态**：四处修复在位 + 规模锚点
2. **构建**：devbuild 三轨 + 聚合驱动器（两次编译覆盖 21 例）
3. **对拍**：分叉必须 0（同 rc · 同 R 码 · 同 stdout）
4. **期望**：strict 12 例三轨**全响亮** · legal 9 例三轨**全绿**
5. **负控 A**：忠实停用 VM 轨判据（C 轨保留）⇒ 必须判红
6. **负控 B**：忠实停用 C 轨两处发射（VM 轨保留）⇒ 必须判红
7. **负控 C**：判据自伤 ⇒ A 的红必须消失
8. **还原**：源逐字节还原 + 复绿

## 五 覆盖边界（如实登记）

- **生成器 lambda**（合成 transform/filter 的形参）**不加检查** —— 实参由运行时按固定个数给出，
  编译期无法判定；本门 `h1` 只覆盖「生成器可正常使用」。
- **默认参数不在尾部**（`def f(a = 1, b)`）不在面内：M90-S1 已定「默认参数在尾部」语义。
- **错误文案**三轨仍不同（缺陷 **186 族**：解释轨指名 `缺少参数 'b'`，
  VM/C 轨给「需 N 给 M」方向词）—— 本门只判 **R 码 + 响亮性 + stdout**，**不按整行文本对拍**。
- **方法面**的 `chan.send` / `mutex.with` 属 M226 门面；本门覆盖用户 impl 方法
  （C 轨直调 / VM 轨经 `px_method`）。
- **原生函数**的 arity 属 M199 门面。
