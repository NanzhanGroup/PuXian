PuXian 仓库 · rpm / dnf · yum

PuXian —— 给 AI 使用的新时代编程语言（Python 语法 + Rust 类型 + Go 并发 + C 出身，编译为 C 静态零依赖单二进制）。

✅ RHEL 9 系（Rocky / Alma / CentOS Stream 9 / Oracle 9）一行安装：

curl -fsSL -o install-rpm.sh https://soft.xiusoft.cn/puxian/install-rpm.sh
sudo bash install-rpm.sh          # 写入仓库 + 导入 GPG 公钥（双验签）
sudo dnf install puxian           # 一行安装
sudo dnf upgrade puxian           # 里程碑自动升级

✅ RHEL 7 系（CentOS 7 / Oracle 7）：同上，包管理器自动识别为 yum（yum install puxian / yum update puxian）。

✅ openEuler 22.03 LTS / 24.03 LTS（M168 新增，x86_64）：同上 dnf install puxian。安装脚本会写入 字面目录 rpm/openeuler/<版本>/x86_64/（不用 $releasever —— openEuler 的它是 22.03LTS，靠它展开必然 404）。

先看后装（免 root，会报出本机该去哪个仓库）：bash install-rpm.sh status ／ 只看将写入的内容：bash install-rpm.sh --dry-run

其它发行版（el8 / Fedora / openEuler 20.03 / 非 x86_64）当前无 rpm 仓库：脚本会打印支持矩阵并给出可执行的替代路线（发布 tarball 或 aarch64 官方引导包）。aarch64 用户请用 puxian-bootstrap-aarch64-<tag>.tar.gz（包内工具链全静态、零 glibc 依赖 —— M168 起）。

两个等价仓库（双活）

同一发布产物在两处等价托管；GPG 签名按内容校验、不绑定域名，两处可互换。

仓库baseurl说明
国内镜像（默认）https://soft.xiusoft.cn/puxian/rpm/…安装脚本内置 3s 探测，通过即用
上游 GitHub Pageshttps://nanzhangroup.github.io/PuXian/rpm/…探测失败自动回退

目录：el7 → rpm/7/x86_64/ · el9 → rpm/9/x86_64/ · openEuler → rpm/openeuler/<ver>/x86_64/；gpgkey 统一在 rpm/PUXIAN-GPG-KEY.asc。

强制指定：sudo PUXIAN_RPM_BASE=<baseurl> bash install-rpm.sh

校验链（GPG 双层签名）

  • 公钥：rpm/PUXIAN-GPG-KEY.asc（下载）
  • 仓库元数据签名：repomd.xml.asc（repo_gpgcheck=1）
  • 包签名：每个 .rpm 内嵌（gpgcheck=1）

镜像状态

镜像自证文件：version.json（版本 / tag / 同步时间 / 发布包 sha256）。

站点在 tag 发布时由 CI 自动更新（rpm/ 树只保留最新版；旧版 rpm 由 GitHub Release 资产留存）。
