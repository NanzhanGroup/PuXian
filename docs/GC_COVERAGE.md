## 二 口径：什么叫「判据强度不足」

同一份派生器（`selfhost/gcroot_derive.py`）有**两个档位**：

| 档位 | 判据 | 用途 |
|---|---|---|
| **`loose`**（默认）| 精确三规则 **+ 任何 `(*x` 形状**（= 可能的间接调用）| **生产判据**（有意过近似，宁多收）|
| `tight` | 仅精确三规则 | **只用于分诊 / A-B**（M213 缺陷 295 定的：tight 会丢失显式 GC 族覆盖 ⇒ 不作默认）|

定义（**这就是本门量出来的东西**）：

```
P_loose   = 产出 GC 管理对象的函数集（producers）
T_tight   = tight 档下「体内可达 gc_register」的函数集（triggers）
WEAK      = P_loose \ T_tight      ← **只有靠过近似才被看见**的桥
STRONG    = P_loose \ WEAK
```

**读法**：`WEAK` 里的函数**体内没有对已知触发点的直接调用**，
被算作触发点**只因** loose 把「函数指针 / 回调」这种可能的间接调用也计入。
⇒ 它们的「产出窗口是否安全」**尚未由精确规则判定**。

**⚠️ 这不是缺陷清单**，是「判据强度」的账。它的价值在于**只许缩小**。

## 三 本机实测（px 0.2.17 · M269）

```
P_loose = 325    T_loose = 543    T_tight = 374
⇒ STRONG = 295   WEAK = 30
```

30 条的**族分布**（每条在 `selfhost/gcroot_coverage.txt` 里带分类标签）：

| 分类 | 条数 | 形状（为什么只有 loose 看得见）|
|---|---|---|
| `quic_h3` | 7 | h3 stream 回调、quic conn 回调、stateless 重试路径 |
| `http_serve` | 6 | route / handler / vhost 经**全局表持有的函数指针**调用 |
| `ws` | 5 | ws handler 回调 + stream 分帧 |
| `sse` | 3 | serve/connect 回调与长连接状态机 |
| `qpack` | 3 | 解码器经静态句柄 / 函数指针调用 |
| `misc` | 6 | 零星单点（`bi_signal` / `px_get_global` / `bi_hex_to_int` …）|

**共同形状**：**回调 / 函数指针**。⇒ 处理方向是
**给回调注册点做「显式触发点标注」**，而不是继续靠 `(*x` 形状兜。

> 📌 与 M213 的 R-B（「全局根可达」豁免）**正交**：
> R-B 管的是「受害者是不是本就是 GC 根」；本表管的是「触发点**从哪来**」。

## 四 判据（六条）

| # | 判据 | 防的是什么 |
|---|---|---|
| ① | **规模锚点**：`P_loose ≥ 300` 且 `T_loose ≥ 500` | 派生器静默失效 ⇒ 空集 ⊇ 任意集 ⇒ **假绿** |
| ② | **划分完备**：`STRONG ∪ WEAK == P_loose` 且不相交 | 分类漏项 / 重叠 |
| ③ | **WEAK 不许扩大**：实测 − 基线 ⇒ 非空即判红（**逐条指名**）| 判据网悄悄破洞 |
| ④ | **基线不许过期**：基线 − 实测 ⇒ 非空即判红 | 把「红」当成「绿」记下来（M226/M227 纪律）|
| ⑤ | **图例双向**：每条登记带**定义过的**标签；每个标签**必须被用到** | 悬空标签 / 无理由登记 |
| ⑥ | **判据自伤**（`--no-weak-check`）：同一假基线 ⇒ 不再红 | 证明红来自**台账判据本身** |

**方向性**：③ 只判「扩大」不判「缩小」⇒ **自然只减不增**（修好一个就删一条）。

## 五 覆盖边界（如实登记）

- `WEAK` 的定义**依赖 tight 档**（= 只用于分诊的档位）⇒ 本台账**不是缺陷判据**
- 它**不保证零缺陷** —— 它让「还有多少地方看不清」变成**可见、可追踪、只减不增**的数字
- **不覆盖**：跨函数 F1 的**间接**调用链（M213 的 F1 只覆盖直接调用）；
  「**后置存活**」（受害者读点是否早于触发点）尚未判据化（M214 登记）
- ⚠️ 与另外两个同族工具**正交、缺一不可**：

| 工具 | 回答的问题 |
|---|---|
| `check_root_contract.py` | **契约合规**（J1–J6：pop/restore 语义、隔离点两类语义）|
| `gcroot_audit.py` | **候选判定**（哪些站点违反「创建后必须登记」）|
| **`check_gcroot_coverage.py`（本文件）** | **覆盖强度**（多少桥只有过近似才看得见）|

